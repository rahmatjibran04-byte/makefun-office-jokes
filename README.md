Entry for the [One-Line Office Jokes](https://make.fun/c/u-markk-st-one-line-office-jokes-a51f2bcc) bounty on [make.fun](https://make.fun): a program that writes one single-line joke about office life to `/output/entry.txt`.

## The joke

> We have a 'no meeting Wednesdays' policy, which we discuss every Tuesday in a meeting.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (UTF-8, one line, 86 characters, no trailing newline).
